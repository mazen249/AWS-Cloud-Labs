## 📌 Overview

This repository documents my hands-on AWS Cloud Engineering labs and practical infrastructure exercises.

The labs are part of my **Cloud Security Engineer learning path**, with a current focus on building practical skills in **AWS cloud infrastructure, identity and access management, compute, storage, networking, and monitoring**.

Each lab focuses on:

* Hands-on configuration and management of AWS services.
* Understanding how cloud resources are deployed and managed.
* Applying access control and security principles.
* Testing configurations and verifying expected results.
* Troubleshooting configuration and access issues.
* Documenting practical implementation steps and technical findings.

## 🧪 Lab Approach

Each completed lab is documented using a consistent structure:

### 📋 Scenario

A practical cloud infrastructure problem or AWS configuration scenario.

### 🔎 Investigation

The information gathered, configurations reviewed, commands used, and troubleshooting steps performed.

### 🛠️ Implementation

The AWS resources and configurations implemented to complete the lab.

### ✅ Verification

Tests performed to confirm that the configuration was successfully implemented and working as expected.

### 📝 Documentation

A clear record of the implementation, screenshots, technical findings, and lessons learned.
